# Contributing to DICOMPUTE/Open

This repository is DiCompute's public issue tracker. It holds no application code, so
most contributions here are **issues**, not pull requests.

## Report a bug or request a feature

- Use **New issue** and pick **Bug report** or **Feature request**. Blank issues are off.
- Give exact reproduction steps and what you expected instead. Those two things
  decide most often whether a report gets fixed quickly.
- How an issue here gets a disposition (`tracked-internally`, `needs-operator`, and so
  on) is written down in [TRIAGE.md](TRIAGE.md).

## Never report a vulnerability in a public issue

Use a private advisory or email security@dicompute.ai. See
[SECURITY.md](https://github.com/DICOMPUTE/.github/blob/main/SECURITY.md).

## Pull requests

Pull requests here are for the tracker itself: the issue forms in
`.github/ISSUE_TEMPLATE/`, `README.md`, `TRIAGE.md` and `releases/`. A fix to the
service lands in the implementation repository, and the issue here is closed by
reference to it.

The organization-wide rules still apply: one concern per PR, explain what changed and
why, and a human merges. See the
[organization CONTRIBUTING.md](https://github.com/DICOMPUTE/.github/blob/main/CONTRIBUTING.md).

## Conduct

Participation is governed by the
[Code of Conduct](https://github.com/DICOMPUTE/.github/blob/main/CODE_OF_CONDUCT.md).

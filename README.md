# DICOMPUTE/Open

Public feature and issue tracker for DiCompute.

**File every issue through the enforced form:** [New issue](https://github.com/DICOMPUTE/Open/issues/new?template=issue.md) — the one source of truth for the format is [`.github/ISSUE_TEMPLATE/issue.md`](.github/ISSUE_TEMPLATE/issue.md) (What / Why / Prompt / Workflow / Loop / Graph / Layout / Flow, ending with the `Severity: … · Effort: …` trailer).

This README intentionally carries no inline template: the form above is the enforced shape, and any copy here would drift from it.

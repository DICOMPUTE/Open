# DICOMPUTE/Open

This is the public issue tracker for DiCompute. It has no application code.

DiCompute is an inference API. Implementation lives in other repositories.
This repository is where anyone can report a bug, request a feature, or
follow existing work.

- [How we handle issues (TRIAGE.md)](TRIAGE.md)
- [Report a vulnerability (do not use an issue)](https://github.com/DICOMPUTE/.github/blob/main/SECURITY.md)
- [Code of conduct](https://github.com/DICOMPUTE/.github/blob/main/CODE_OF_CONDUCT.md) ([dicompute.ai/conduct](https://dicompute.ai/conduct))
- [Help for account and billing](https://dicompute.ai/console)

Use **Bug report** or **Feature request** on the New issue page. **Engineering
issue (team use)** is the internal eight-section spec; you do not need it to
report a problem.

# Feature Issue Template

Every issue in this repository is written in one format: eight sections, in order,
ending with a Severity · Effort line.

- **What**, **Why**, **Prompt**, **Workflow**, **Loop**, **Graph**, **Layout**, **Flow**
- a final `Severity: … · Effort: …` line

The enforced form is [`.github/ISSUE_TEMPLATE/issue.md`](.github/ISSUE_TEMPLATE/issue.md).
Start a new issue from the form, not from a copy of this page: blank issues are
disabled, so the form is the only way to file one. The form's comments explain
each section and the severity and effort scales.
